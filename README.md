# MoneyTable-Ai 💰

Простое веб-приложение для учёта личных финансов на чистом **HTML, CSS и JavaScript**. Фреймворки, сборка и внешние зависимости не нужны.

🔗 **Демо:** https://leshashirokov.github.io/MoneyTable-Ai/

## Страницы

Сверху на каждой странице есть общая навигация: текущий раздел подсвечен, меню адаптивное и работает с клавиатуры. Там же кнопка переключения темы, а выбранная тема запоминается.

| Страница | Файл | Что там |
|---|---|---|
| 📊 **Статистика** | `index.html` | Сводка (баланс, доходы, расходы, свободный остаток) за месяц или всё время. Кольцевая диаграмма расходов или доходов по категориям. Столбцы «доходы против расходов» за 6 месяцев (клик по месяцу выбирает его периодом). Менеджер категорий. |
| 🐷 **Копилки** | `goals.html` | Цели: создание, редактирование, удаление, пополнение и снятие, история, прогресс. Экспорт копилок в CSV. |
| 📒 **Журнал** | `journal.html` | Форма добавления и редактирования операции, таблица с фильтрами, поиском и сортировкой, итоги по выборке. Экспорт CSV, демо-данные, очистка всех данных. Менеджер категорий. |

## Возможности

- **Свободный остаток** — это баланс за всё время минус деньги в копилках.
- Поля операций проверяются. Фильтры работают по типу, категории и месяцу, есть поиск по тексту и сортировка по дате или сумме.
- Диаграммы нарисованы в SVG без библиотек и используют цвета категорий.
- Экспорт в CSV открывается в Excel: разделитель `;`, кодировка UTF-8 с BOM.
- Есть светлая и тёмная тема, адаптивная вёрстка и доступная разметка.
- Все страницы работают с одними и теми же данными в `localStorage`. Изменения из другой вкладки подхватываются автоматически.

### Категории

Кнопка «⚙ Категории» есть на страницах «Статистика» и «Журнал». Она открывает отдельные списки для расходов и доходов.

- Категорию можно добавить, переименовать или удалить и выбрать ей цвет.
- Пустые и повторяющиеся названия не принимаются.
- При переименовании все операции этой категории обновляются.
- Если удаляемая категория уже используется, приложение предложит перенести её операции в другую категорию или в «Без категории».

### Копилки

- У цели есть название, сумма, необязательный срок, эмодзи и цвет.
- Если задан срок, показывается, сколько нужно откладывать в месяц.
- Пополнение и снятие указываются с датой и необязательным комментарием. Снять больше, чем накоплено, нельзя. Если пополнение больше свободного остатка, приложение предупредит.
- Пополнение копилки не считается расходом: деньги остаются в балансе, но уменьшают свободный остаток.

## Запуск

Откройте `index.html` в браузере, больше ничего не требуется (страницы работают и через `file://`).

## Структура

```
index.html     — 📊 Статистика
goals.html     — 🐷 Копилки
journal.html   — 📒 Журнал
style.css      — общие стили и темы
js/theme.js    — применяет сохранённую тему до отрисовки (без мигания)
js/common.js   — общий код: хранилище и миграция, состояние, форматирование,
                 тема, диалоги, CSV, менеджер категорий (window.MoneyTable)
js/stats.js    — логика страницы «Статистика»
js/goals.js    — логика страницы «Копилки»
js/journal.js  — логика страницы «Журнал»
```

Скрипты обычные, не ES-модули, поэтому страницы открываются и с диска. Порядок подключения: `common.js`, затем скрипт страницы.

## Данные

Ключи в `localStorage`: `moneytable-transactions`, `moneytable-categories`, `moneytable-goals`, `moneytable-theme`, `moneytable-initialized`.

- Данные из прошлых версий (одностраничной и самой первой) читаются без потерь. Если в операциях есть категории, которых нет в списке, они добавляются в список автоматически.
- При первом посещении любой страницы загружаются демо-данные.
- «Очистить всё» в журнале удаляет операции и копилки, а категории сохраняет.
