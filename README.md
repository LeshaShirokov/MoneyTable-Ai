# MoneyTable-Ai 💰

Простое веб-приложение для учёта личных финансов на чистом **HTML, CSS и JavaScript**: без фреймворков, сборки и внешних зависимостей.

🔗 **Демо:** https://leshashirokov.github.io/MoneyTable-Ai/

## Возможности

- Сводка: баланс, доходы и расходы за выбранный период
- Добавление, редактирование и удаление операций с проверкой полей
- Фильтры по типу, категории, месяцу, поиск по тексту и сортировка по дате или сумме
- Диаграмма расходов по категориям (SVG, без библиотек) с легендой
- Экспорт в CSV и полная очистка данных с подтверждением
- Светлая и тёмная тема, адаптивная вёрстка, доступная разметка
- Данные хранятся в `localStorage` вашего браузера

## Запуск

Откройте `index.html` в браузере. Больше ничего не нужно.

## Структура

```
index.html   — разметка
style.css    — стили и темы
script.js    — логика приложения
```
