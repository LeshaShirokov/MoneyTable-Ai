# MoneyTable-Ai 💰

Простое веб-приложение для учёта личных финансов на чистом **HTML, CSS и JavaScript**. Фреймворки, сборка и внешние зависимости не нужны.

🔗 **Демо:** https://leshashirokov.github.io/MoneyTable-Ai/

## Возможности

- Сводка: баланс, доходы и расходы за выбранный период, а также **свободный остаток** (баланс минус деньги в копилках)
- Добавление, редактирование и удаление операций с проверкой полей
- Фильтры по типу, категории и месяцу, поиск по тексту, сортировка по дате или сумме
- Диаграмма расходов по категориям (SVG без библиотек) с легендой в цветах категорий
- Экспорт операций и копилок в CSV, полная очистка данных с подтверждением
- Светлая и тёмная тема, адаптивная вёрстка, доступная разметка
- Данные хранятся в `localStorage` вашего браузера

### Категории

Кнопка «⚙ Категории» открывает отдельные списки для расходов и доходов.

- Можно добавить, переименовать или удалить категорию и выбрать её цвет для диаграммы.
- Пустые и повторяющиеся названия не принимаются.
- При переименовании все операции этой категории обновляются.
- Если удаляемая категория уже используется, приложение предложит перенести её операции в другую категорию или в «Без категории».

### Копилки

- У цели есть название, сумма, необязательный срок, эмодзи и цвет.
- Прогресс-бар показывает, сколько накоплено и сколько процентов цели выполнено. Если задан срок, выводится сумма, которую нужно откладывать в месяц.
- Пополнение и снятие указываются с датой и необязательным комментарием. Снять больше, чем накоплено, нельзя.
- Если пополнение больше свободного остатка, приложение предупредит, но операцию разрешит.
- Копилку можно отредактировать или удалить (с подтверждением). Достигнутая цель получает отметку «Достигнута», у каждой копилки есть своя история операций.
- Пополнение копилки не считается расходом: деньги остаются в балансе, но уменьшают свободный остаток.

## Запуск

Откройте `index.html` в браузере, больше ничего не требуется.

## Структура

```
index.html   — разметка и диалоги
style.css    — стили и темы
script.js    — логика приложения
```

## Данные

Ключи в `localStorage`: `moneytable-transactions`, `moneytable-categories`, `moneytable-goals`, `moneytable-theme`.
Данные из старой версии переносятся автоматически, и операции при этом не теряются. Если в операциях есть категории, которых нет в списке, они добавляются в список.
